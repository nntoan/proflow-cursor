# tweakcursor v0.1.0 — First Release

**Release date:** 2026-10-30 (pending npm publish) · **Package:** [`tweakcursor`](https://www.npmjs.com/package/tweakcursor) · **License:** MIT

tweakcursor patches the locally installed **cursor-agent** CLI: it disables
third-party plugin imports (which have no official off switch), recolors diff
highlights, guards patches against cursor-agent's background self-updater, and
offers sandboxed ad-hoc edits. It is a patcher only — it ships no Anysphere code.

> **Unofficial.** Not affiliated with, endorsed by, or supported by Anysphere.
> Modifying local installation files may conflict with the
> [Cursor Terms of Service](https://cursor.com/terms-of-service) (§1.5). Review and
> decide for yourself; use at your own risk. A valid Cursor subscription is required.

## Highlights

- **Interactive TUI wizard** (Ink 6 + React 19): installation picker → patch
  toggles → theme editor → update guard → apply → report. `npx tweakcursor`.
- **Full non-interactive CLI** for scripting: `--apply`, `--restore`,
  `--list-patches`, `doctor`, `adhoc-patch` — exit codes `0/1/2/3`.
- **Five built-in patches**, each anchor-verified against cursor-agent
  **`2026.10.22-27dcf5f`** (see table below).
- **Safety-first engine**: backup before first write, restore-before-apply
  (idempotent, non-additive), per-patch atomicity, JS parse gate on every write,
  post-apply boot smoke test with automatic restore.
- **Posture B** on unverified versions: loud per-patch warnings, attempt anyway,
  failures isolated per patch — never a partially applied patch.
- **Sandboxed adhoc scripts** under Node's permission model (no fs-write, no
  network, no subprocess) with diff preview and confirm.

## Built-in patches

| Patch | Default | Effect |
| --- | --- | --- |
| `disable-third-party-plugins` | on | Forces `importThirdPartyPlugins` false at loader, filter, and headless-wiring sites |
| `disable-third-party-extensibility` | off | Forces `thirdPartyExtensibilityEnabled` false at construction/default sites |
| `patched-indicator` | on | `[tweakcursor]` in the `--help` description (display sites only; version sources never touched) |
| `themes` | off | Rewrites diff-highlight hex tables from preset or custom palettes |
| `update-guard` | on | Sets official `disableAutoUpdate` in `~/.cursor/cli-config.json` (merge-only) + startup reminder in the bundle |
| `adhoc-patch` | — | Subcommand: one-shot `--string`/`--regex`/`--script` edits with occurrence indexing and `$N` groups |

## Requirements & support matrix

| | |
| --- | --- |
| OS | macOS, Linux |
| Node | ≥ 20 (adhoc script sandbox needs the permission model; flag spelling adapts to Node 20–22 vs 23.5+) |
| cursor-agent | plain-JS install at `~/.local/share/cursor-agent/versions/{version}/` |
| Anchor-verified version | `2026.10.22-27dcf5f` — other versions get posture-B behavior |

## Install & quickstart

```bash
npx tweakcursor            # wizard
npx tweakcursor doctor     # inspect first: installs, backup, cli-config, matrix
npx tweakcursor --apply    # non-interactive (add -y to skip the prompt)
npx tweakcursor --restore  # back to pristine at any time
```

After every cursor-agent update, re-run `tweakcursor --apply` (the update-guard
patch plus the official `disableAutoUpdate` key prevent silent updates in the
first place).

## Configuration

- `~/.tweakcursor/config.json` — per-patch `{enabled, options}`, theme palette,
  `changesApplied`. Override dir with `TWEAKCURSOR_CONFIG_DIR`.
- `~/.cursor/cli-config.json` — written merge-only, unknown keys preserved.
  Override path with `TWEAKCURSOR_CLI_CONFIG_PATH`.
- `TWEAKCURSOR_INSTALL_PATH` / `--install-path` — select a specific version dir.
- `--config-url {url}` — remote config as *defaults only*; local config wins.

## Known limitations

- **Windows is not supported** (v1 targets macOS/Linux plain-JS installs).
- Themes v1 rewrites the diff hex tables only; named Ink colors are untouched.
- On unverified cursor-agent versions, patches may fail (loudly, safely) —
  re-verification happens per release.
- No automatic re-apply hook yet (post-v1 milestone).
- Running cursor-agent instances are detected (`.running/{pid}`) and reported by
  `doctor`, but patches apply to files on disk — restart sessions to pick them up.
